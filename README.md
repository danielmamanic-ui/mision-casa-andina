# Misión Casa Andina · Grupo 5

Presentación interactiva del trabajo final de Base de Datos (Tecsup, 2026): modelo relacional de Hoteles Casa Andina, versión 5.4, con 36 tablas en 6 áreas.

**Ver en línea:** https://danielmamanic-ui.github.io/mision-casa-andina/

## Cómo usarla
Abre `index.html` en Chrome o Edge. No necesita instalación.

| Tecla | Acción |
|---|---|
| → | Avanza y dispara las conexiones clave |
| ← | Retrocede |
| F | Activa la pantalla completa |
| G | Abre el panel de apoyo |
